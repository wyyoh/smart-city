# 材料方案工作台界面约定

使用者是养护与材料工程师，主要任务是把场景要求与材料试验依据放在一起比较。

配色为工程蓝183B54、试验青007F82、冷灰F4F7F9、纸白FFFFFF、深灰3C4A55和警示琥珀B16A11。字体以等线和微软雅黑呈现中文，Bahnschrift用于对齐数字。主界面左对齐，保留适合工程数据的紧凑行距。

布局采用窄导航、场景工作台和可展开的依据面板。场景输入占页面左部，右部由性能对比表与级配曲线主导。原始单元格、组内记录与判定条件随选中方案展开。移动端依次排列输入、候选和依据。

第一版草案中的首页统计卡已删去，因为总数不能回答材料是否满足当前场景。视觉重点放在性能相对目标的余量以及缺测位置，状态由文字与颜色共同表达。没有指标或成本数据时显示具体缺项。

界面不重复后端阈值判定；历史聚合、审核试验和模型预测分别标记。模型缺席、规则冲突、候选为空和修改后待验证均属于正式页面状态。
