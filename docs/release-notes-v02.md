# 数智选材 v0.2.0

本版本沿用既有FastAPI、SQLModel、SQLite和React工程，实现从三类构造养护场景到可解释材料方案的完整流程。原工作簿、赛题PDF、旧计划、旧模型和原始目录行保持不变；旧/v1接口及固定小池回归继续保留。

新增/v2需求解析和确认，规则、来源及覆盖理由留痕；从全目录按库存、级配与明确相容条件检索，保存候选范围及证据哈希；逐要求返回满足、不满足、缺测、不可比。可行候选按场景偏好透明比较，硬失败不被综合分抵消。

无解诊断绑定需求和候选池，证书列出包含关系下最小冲突及删除任一要求后的候选见证。未知项不能证明无解，空池另列。代码、数据、反馈、规则或候选变化可被识别；旧快照可重放，新生成和上游选择拒绝过期版本。

材料卡显示完整已知组成与未披露项，微调不继承父实测。验证卡含候选、项目、条件、理由和停止规则。实测、各指标自身离折验证与研究全量拟合分开；四项现有模型外层MAE未优于均值基线，保留实际负结果。实验室与现场反馈分开，本地上游模拟不会触发真实企业请求或自动模型发布。

五案主对照使用相同84条AC-13目录池、相同数值要求。B1与V2可行数一致：2、2、5、1、0。C5在此范围为证据不足；限定35条完整数值子池后可复核四组最小冲突。三个规则场景与C4/C5明确选择的附加构造要求模板区分展示。

验证：65项Python检查、前端类型及生产构建、12类负例、双尺寸浏览器检查、2400ms慢响应与异常恢复、两次隔离完整排练均已完成。原8项受保护文件与6张原库表核对未变。打包后另核对全文件哈希、搬迁路径、旧接口、模型、V2需求到C5证书与HTML报告。

启动用README中的本地脚本；新机器需先安装锁定依赖，运行核心流程无需公网。发布包不捆绑Python/Node解释器，不称全新操作系统或企业生产部署验收。压缩JSON快照可用Python gzip.open读取，完整证据无损保留。
