# 数智选材的创新与案例证据

核心主张：面向数据不完整的道路养护选材，把场景要求、方案取舍和配方调整连接成可解释、可追溯的协同决策过程。

| 工程问题 | 基准方法能够做到 | 本作品增加的操作能力 | 演示证据 |
| --- | --- | --- | --- |
| 要求从哪里来 | 工程师给定阈值后全约束查表 | 规则、要求出处与人工覆盖一起保存 | C1，三类场景解释 |
| 多种材料都合理，怎样选 | 在同一可行集合中按预设指标排序 | 切换指标优先顺序，显示数值取舍并保存理由 | C3，五项可行不变，首位H变K |
| 选定后怎样继续设计 | 查表产生历史候选 | 从准确父配方保留原需求、改动和设计意图，保存独立草案 | C2，油石比4.9%到5.0% |
| 没有推荐时怎么办 | 报告可行数为零 | 区分证据不足与明确候选范围内的冲突，提供下一步方向 | C5，84条含缺测目录与35条诊断子池 |

本作品的贡献在于这些机制的连续使用与数据状态处理。全约束基准B1与作品在五案中的可行数均为2、2、5、1、0；相同结果为比较前提，新增能力通过过程记录展示。Pareto分析、字典序排序和最小冲突本身均不作为原创数学算法声明。

答辩主线采用C1解释需求，C3展示取舍，C2继续设计，C4演示要求变化，C5解释无结果。计算预测和逆向生成作为技术深化路线，当前不主张已生成性能改善的新材料。
