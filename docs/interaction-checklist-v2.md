# v0.2 交互验收

验收执行者为 AI，使用隔离的 ui-review.sqlite 与 2400 ms 延迟服务，记录在 artifacts/next-phase/ui-review/review.json。正式目录和原工作簿未改写。

- 1440×900 和 1280×720：需求、材料组成、冲突证书、补测卡可阅读与操作；文档无横向溢出，表格支持局部滚动。
- 需求与生成响应：旧需求响应返回后不能覆盖已选择的新场景；改变证据视图会取消旧生成响应的显示。
- 键盘：Tab 到确认按钮后 Enter 提交；Enter 展开冲突见证及微调区域；状态都有文字。
- 错误恢复：仅QA服务的 UI_ERROR_FIXTURE 返回503；界面显示错误，修正输入后可生成确认。
- 空库存生成空池，完整缺测池为证据不足，完整数值子池才给相应已知冲突；报告注明范围。
- 正式项目可输入实际气候、交通、试验方法与条件；PG等级等合法需求保留，能力不足不替换为现有指标。
- QA-TIE-R1 是只在隔离UI库中复制的合成并列夹具；界面显示并列，不计新增独立配方、来源或试验。
- 历史快照可重放；输入变化及候选/规则/数据/代码版本改变有明确提示；微调不继承父实测。
- 源单元格可追到原值与公式；暂按独立的记录不称已确认独立批次。
- 模型视图区分实测、各指标自身离折预测与研究全量拟合，实际负结果可见，未提供联合达标概率。

这些是软件交互验收，不是工程适用、真人操作效率或行业收益证明。截图随检查记录保存。
