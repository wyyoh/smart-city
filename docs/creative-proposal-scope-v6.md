# 数智选材创意方案定位与推进重点

本次作品交付定位为有创新性和实用性的创意方案，并用现有原型与案例说明关键机制。实物材料实验、真人测时和生产系统部署属于后续工程化拓展，不作为本轮完成条件。

赛题第4页明确“参赛成果以创意方案为主，不要求完整工程实现”，同时要求逻辑自洽、数据来源可行、关键技术路线清晰，并说明创意的新颖性与可行性。实验室性能验证列在加分成果中。基本成果仍需完整技术方案、可演示原型、至少3类典型场景、不少于5个合理案例及基准对照、交接说明和潜在应用价值分析。

## 作品的核心主张

数智选材把养护需求转化为可解释、可比较、可人工调整的材料设计方案。工程师输入路段场景后，系统识别性能需求、形成候选方案、解释权衡，再允许工程师调整条件或组成并比较变化。

创新性重点放在以下三个机制的衔接，不把采用某种常见算法本身当作原创贡献。

| 亮点 | 要解决的问题 | 创意设计与演示支撑 |
| --- | --- | --- |
| 场景驱动的可解释推荐 | 养护要求与材料参数之间缺少清晰连接 | 把场景映射、需求来源、材料关联和推荐理由组织为同一流程；用C1说明“为什么适合这个场景”。 |
| 多目标权衡与冲突解释 | 目标相互制约时，单一评分难说明如何取舍 | 区分硬约束、优先级和未知条件，展示候选对比与范围内冲突见证；用C5解释调整哪项要求会改变结果。 |
| 人机协同的配方演化 | 自动输出后，工程师难以继续调整和判断影响 | 结合设计假设、人工微调、组分差异和方案版本，说明“改了什么、为什么改、需要重新判断什么”；用C2展示交互过程。 |

技术方案进一步说明目标驱动候选生成、多任务预测、材料与工艺适配的输入输出、算法逻辑和数据需求。已有原型实现与拟议技术分别标注；当前有限配方目录不表述为已能可靠设计任意新材料。

## 实用性如何说明

用高温重载、寒冷裂缝、水损害及组合约束等五个案例，展示从场景输入到推荐依据的完整操作。每案对照同一候选范围的基准方法，解释系统在需求组织、方案比选、冲突诊断、调整记录方面给工程师增加的价值。案例可以合理构造，必须说明其身份和假设。

数据可行性由企业提供的工作簿、结构化数据模型、规则来源和可复用接口说明支撑。缺少的改性剂、环境或工艺字段在技术设计中给出数据需求与处理路径。成本、寿命、碳排和设计周期可以给出评估框架或明确假设的情景测算，不填写为已经发生的收益。

## 现有成果的用途调整

已有预测模型、集成实验和复现记录保留为建模可行性的辅助依据。后续不再围绕必须让全部指标击败基线反复试验；答辩重点是设计逻辑、小样本策略、数据条件和适用范围。

1098个计算配方假设用于说明候选设计空间和人机交互，不需要全部制造或送检。源表复核清单说明数据治理思路；五配方送检资料与外部核验模板保留为孵化参考，界面移至可选拓展区域。

历史数据、计算预测与构造案例继续保留各自身份。取消实物实验交付要求不改变这些数值的含义，也不将新配方预测改写为实测。

## 下一轮的完成标准

按单人每周15至20小时，下一轮安排18小时核心工作和2小时缓冲，约1至2周：完善技术方案4小时，打磨三项亮点4小时，整理五个案例4小时，实用性与落地路线3小时，参赛表达与问答3小时。具体任务见 `planning/creative_proposal_phase_v6.json`，全部为下一轮计划，不代表已经完成。

验收时集中回答三个问题：创意比现有查表和单指标预测增加了什么决策能力；工程师在什么场景下如何使用；现有数据、算法与模块为何足以支撑概念原型。获选后再考虑新增材料实验、真实联调和规模化部署。
