# 任务价值验证口径

本轮先采用AI自测。artifacts/next-phase/workflow-value.json记录三项代表任务、每项三种流程代理：人工表格核对的脚本代理、原B1加明确记录的软件补充审计、V2原生流程。每项使用同一冻结候选池、阈值和可见证据，报告准备阶段、执行顺序、软件操作及实际时延。

人工流程代理不是人工测量。真人参与者数量为0，人工操作次数与有效时间均为空。API、CPU、序列化和共同准备过程会影响时延，不能据此计算真人节时百分比，也不估计行业平均收益。浏览器AI自测另记录在ui-review/review.json。

目前可核查的价值是自动保留场景到要求的出处、候选范围和版本、未知状态、冲突及删除见证、微调失效和验证停止条件。五案已正确给定全部数值要求时，B1与V2可行集一致，不能把这部分包装成准确率增益。

真人复核时按三项任务分别操作人工、B1、V2，轮换顺序并记录参与者背景、开始结束时间、操作日志、遗漏及追溯结果；中断和学习时间单列。重复运行脚本不增加参与者数。真人测时、独立材料试验、价格碳排寿命及企业联调继续保持待验证。
