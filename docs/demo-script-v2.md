# 数智选材演示练习脚本

3分钟核心与8分钟详细是练习安排，未据此假定官方答辩时限。以下时段为计划分配，不是已测得真人演示时长。启动服务后先验证版本、模型与目录，演示使用构造范围。

## 3分钟核心

0:00–0:35 打开场景选材，选高温、低温或水损害条件并生成需求卡。说明：“系统先检查工法、层位、气候、交通、病害与严重程度，再给出有来源的性能要求。这里的量化映射是团队构造示例；未知条件不套默认地区，工程师修改有原值和理由。”确认需求。

0:35–1:25 选择C5，先生成完整目录结果，再切换完整数值演示子池。“84条目录含缺测，只能说证据不足。限定35条完整记录后，每个候选都有已知失败，可以给出四组最小冲突。”展开一组，指出删除任一要求后的候选见证，以及需求与池指纹。“这是池内结论，不是材料物理定律，也不会自动放宽正式要求。”

1:25–2:05 切回C1，查看完整材料卡和原单元格。“产品、级配、用油、名义RAP与施工条件放在一起。未披露改性剂和助剂保持未知。数值满足与工程适用是两件分别检查的事。”展示原始值与方法条件未知。

2:05–2:40 展示微调入口和验证卡。“新版本不继承父实测。下一步给出要补的项目、待确认条件、理由和停止规则；已知失败材料不会被说成只差补测即可可行。”新建微调仅在排练时间允许时执行；创建后重新生成并查看待补证据版本。

2:40–3:00 打开决策报告。“五案B1与V2数值可行集一致，我们的新增价值在需求、证据、诊断和验证行动的完整留痕。65项软件检查与两次隔离排练通过，真实材料适用和真人收益仍需外部验证。”

## 8分钟详细

0:00–1:00 交代企业课题一与五项基本成果，说明三条亮点。展示180历史操作键、84条AC-13目录与35条完整数值子池的区别，不称独立配方数量。

1:00–2:00 在三类场景之间切换，展示目标和优先级变化、规则来源及版本。把严重程度改为未知，显示没有适用规则。恢复后演示人工覆盖留痕；C4/C5附加目标明确标为选择的构造模板。

2:00–3:00 确认需求并冻结全目录，显示入选与排除原因。并排看两种材料的产品、级配、用油、RAP和未知组成。解释四态、硬失败不补偿、并列和未知价格维度。

3:00–4:20 演示C5完整目录与完整数值子池的区别，展开冲突及删除见证。展示证书验证记录；改动目标或候选后需重新确认/冻结，旧报告保持原内容。

4:20–5:20 查看源单元格、试件标签与疑似均值说明。展示方法、条件、层位和施工分别为未知/不相容的处理；演示预算缺少价格不能判断。展示PG或疲劳合法需求保留为能力缺口。

5:20–6:20 创建标为演示的微调版本，重新检索确认父实测没有继承。查看验证卡的候选、项目、条件、理由与停止规则。说明高级决策价值补测属于延后研究，没有宣称最优或节省费用。

6:20–7:10 查看模型验证，依次指出实测、该指标自己的离折预测、全量拟合研究预测及区间。说明四项外层MAE均未优于均值基线，独立分折不是共享验证，单指标区间不是联合达标概率。

7:10–8:00 展示五案同池对照、两次完整排练、搬迁包与接口契约。本地上游请求保留决策及区段，实验室与现场反馈分开。结束时指出已完成的软件能力，以及真实工程要求、独立试验、真人测时和企业联调的下一步证据。

## 排练检查

选定清洁演示库，确认没有QA-TIE等界面夹具；有意识地区分完整目录与完整数值子池；预先打开需要的报告。接口失败时显示错误和重试，禁止切换到未标注的预制成功截图冒充实时结果。软件排练记录在rehearsals，真人讲解与操作时间另记。
