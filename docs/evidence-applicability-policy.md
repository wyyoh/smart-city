# 证据适用性策略 v2

数值判定与证据适用分别返回。每项证据核验单位、试验方法、该指标所需条件、数据范围、工法、层位、结构与设备/窗口。状态为适用、不适用、未知；只有正式模式中全部适用才允许比较为满足或不满足。缺少数值为缺测，已有数值但口径不足为不可比。

有明确不兼容的工法、层位或结构在检索时排除；方法或试验条件不匹配时保留记录并标为不可比。设备需求与现有设备不兼容会阻止正式适用。施工窗口目前为已确认的相容窗口标识，系统不从任意文字推算温度区间。

构造场景可声明 legacy_workbook_numeric_demo 并比较四项历史聚合值；界面始终另列工程适用未知。演示例外不会覆盖明确不兼容证据。历史方法、条件、来源独立性和配方身份未经外部核验。

预算缺少价格或同一计价单位时为缺测或不可比；碳排和供货同理。RAP质量基准未确认时，正式要求不可比，演示可使用带明确名义口径的值。未披露改性剂、助剂、设备与工艺不得填零或视为无约束通过。

本策略核查证据字段与声明，不替代工程师的资料真实性审核，也不构成材料发布批准。
