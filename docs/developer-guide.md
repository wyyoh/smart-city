# 开发与交接说明

## 结构

`backend/app/importer.py` 校验布局并保留原始行；`storage.py` 存储数据版本、操作配方、标签、微调、试验和报告；`services.py` 执行规则与状态流转；`domain/contracts.py` 定义输入、单位与运算符；`ml/` 提供设计前特征、分组实验与研究预测。`frontend/src/` 是 React TypeScript 工程师工作台。

数据目录默认 `data/workbench.sqlite`。测试通过临时库复制隔离，不能用生产库执行写入测试。可用 `ASPHALT_DATABASE` 指定其他 SQLite 路径。数据库含全部原始行，量值沿用表内缓存结果并保留公式；不尝试在Python中重新计算Excel公式。

## 身份与字段质量

同一来源、完整级配、局部产品和油石比形成操作配方键，不代表经过确认的独立物理配方。只展开Excel真实合并区域。别名没有企业证据时保持conditional，confirmed_alias集合目前为空。B的多个命名方案按试件名称保留；M-1体积表90#-3不自动合到90#。

TSR小数转换为百分数一次；残留稳定度原值已为百分数。缺测为null，零值保留。21组DS的疑似第三均值保留原值但不增加暂按独立数。TSR和残留比是原表组比值，独立批次未知。52项曲线差异与T的用油异常不自动修正，前者影响曲线特征，后者隔离相关设计前训练输入。

## 规则与版本

企业流程参考值为DS>800、应变>2000、TSR>75、残留稳定度>85；出处为设计流程E10至E12。项目修改目标后，来源切换为project_target。区间闭合，严格大于不包含相等。硬约束失败与缺测分别保存，未知价格不能满足预算约束。排序仅使用通过筛选后的偏好值，没有综合分抵消失败。

报告快照保存输入、来源与结果、规则版本、导入器版本、原文件SHA256与数据修订。快照哈希按排序JSON计算，不包含报告ID、生成时间和哈希本身。审核后的新观察仅影响新的推荐，旧报告可按ID读取。

## 微调与试验

微调产生新ID与parent_id，记录changes与理由，所有父实测标签失效。RAP变化使旧合成级配失效；未确认质量基准时不推导新级配。产品或用油变化也必须重新试验。

试验先为draft，具有幂等键、试验组、方法、条件、原始记录位置、组内试件数、单位和demo/official范围。批准或驳回后记录不可编辑；修订需新增记录引用supersedes_id。用于推荐前必须确认条件。相同方案与指标采用最新批准记录，不把不同试验组未经确认地混合平均。演示回流只在constructed_demo场景可用，正式项目与模型训练排除演示数据。当前无账户权限和双人审核，不能代替企业试验管理系统。

## 模型实验

使用名义RAP、油石比、AC公称尺寸、沥青名义牌号指示与可信原表级配曲线。名义牌号不是实测针入度；后验VV/VMA、稳定度和任何目标值不能作为特征。缺失填补和缩放在每一允许训练部分拟合。

来源代码共享完整非零原料曲线时合并分组，至少两类非矿粉组分，避免因通用矿粉而把全库合成一组。仍不能断言这些分组等价于独立物理料源。每个指标使用自己的有效标签与分组，剔除关联不明、RAP或用油缺失、T异常输入。

均值、近邻、Ridge、随机森林与固定核GPR在相同外层5折评价；内层3折比较参数与模型，最多9个候选管线、每棵森林80树、每指标120秒上限。保存每折ID与分组、离折预测、MAE/RMSE/R²及企业参考和演示阈值误判数。全量重拟合模型通过全数据内层选择，用途限定为研究；其训练内预测不能拿作泛化成绩。

区间另用固定种子的训练、12个校准组、8个测试组。用校准组最大残差的90%有限样本分位数构建组区间，报告行覆盖、组覆盖和宽度；这需要组可交换性假设。展示区间时使用该校准模型自身的中心，不拼接另一全量模型的点预测。四项分别校准，不是联合达标概率。负的物理下界保留为研究区间计算值，不宣称可实现性能。

API拒绝代码、特征、文件哈希或数据版本不匹配的模型；未知名义牌号或缺少设计输入返回abstained。数值超出训练设计范围、最近邻距离超限则标记外推。所有预测保持research_only，不参与历史硬约束通过判定。
