# 下一阶段增量契约边界

基线为0.1.0，冻结清单见next-phase-baseline.json，隔离数据库备份位于artifacts/next-phase/baseline。原始工作簿、历史配方与旧验收记录保留，新增需求记录和推荐快照采用独立版本。

新增接口采用/v2前缀，保留/v1输入输出兼容。场景输入、性能目标、规则来源、人工确认、候选池及证据状态分别建模；已知但未支持的指标必须保留。旧接口的四指标限制不作为新场景契约的能力上限。

构造演示规则只适用于明确选择的演示上下文；正式项目要求需给出处、方法、条件和确认状态。缺少规则或条件时保留待确认，不生成精确默认要求。模型继续保留研究状态。

验证使用临时库或ASPHALT_DATABASE指定的隔离副本。隔离验证不得向正式目录写入演示观察。基线数据库为只读来源，在线备份不覆盖原库。

执行状态另存于artifacts/next-phase/execution_progress.json，规划清单保持原估算。自动执行的墙钟时间不等于用户有效开发工时，actual_hours在没有人工工时记录时保持null。
