# 案例与设计工作区界面设计

沿用数智选材现有的工程工作台视觉：墨蓝文字#183b54、青绿操作色#007f82、白色工作面#ffffff、浅蓝灰分区#eef5f7、边界#dce5e9，琥珀#bd6b24仅标识待确认状态。使用现有微软雅黑与等线字体，正文13至14px、段落行高1.6，性能数字采用等宽数字特性。界面与资源保持本地可用。

布局采用左侧五案选择、右侧连续决策工作纸。实际操作顺序为场景需求、方案取舍、继续设计；这三段具有步骤编号。各段使用横向分隔组织信息，避免将内容分成相同的装饰卡片。双轴比较图是主要视觉焦点，周围的来源与解释保持简洁。

桌面上比较图与候选表并列，窄屏按顺序堆叠。场景摘要优先显示当前病害、性能要求及来源；详细方法条件收进可展开区域。候选数据保留原单位和目标线。选中方案后显示完整材料卡及原始单元格入口。

配方探索始终带着准确父方案和原需求。锁定项使用原生复选框，设计意图使用有名称的文本框，保存结果提供返回、JSON与打印入口。空结果明确说明如何解除锁定或返回，不自动换成其他配方。

风格复核结论：保留已有产品字体、色彩和导航；以工程师正在做的比较为主要画面。功能性图表、要求出处和组成差异承担信息表达，装饰动画不进入核心工作。关键操作支持键盘，状态同时有文字说明。
